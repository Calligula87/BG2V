BG2V WINDOWS SETUP
==================

1. Double-click "Prepare BG2V.bat".
2. Select your legally obtained Baldur's Gate II Android APK.
3. Wait for the success message.
4. Copy the generated "bg2v" folder into "ux0:data/" on your Vita.
5. Install BG2v0_beta.vpk with VitaShell and launch BG2VBETA.

If "ffmpeg.exe" is next to the setup batch file, startup videos are optimized
automatically. Otherwise they are skipped by default to avoid stutter.

No Python, WSL, or command-line knowledge is required.
